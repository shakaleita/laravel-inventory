# Contributing to Laravel Inventory

This is a standalone portfolio project. Improvements should focus on readable, testable domain workflows.

1. Create a feature branch. Keep changes focused.
2. Follow existing project conventions, and do not include secrets, local databases or dependencies.
3. Add or update automated tests for changed behaviour.
4. Run the project's documented test command before proposing a change.
5. Explain the motivation, screenshots for UI changes, and any security implications in the pull request.

Please use issues to discuss large design changes before implementation.
